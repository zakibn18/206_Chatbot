Tentang AI Chatbot Service

Aplikasi frontend modern untuk proyek Pengembangan Web Service - Pertemuan 10.

Model LLM: openrouter/free
Protokol: Server-Sent Events (SSE) Streaming
Endpoint: POST /api/chat
Format Payload: { "message": [{ "role": "user", "content": "..." }] }
Fitur Utama:
  • Streaming respons secara real-time dengan efek pengetikan halus
  • Render format Markdown lengkap & Syntax Highlighting blok kode
  • Tombol sekali klik untuk menyalin kode
  • Penyimpanan riwayat percakapan otomatis di peramban (localStorage)
  • Dukungan Tema Gelap (Dark) dan Tema Terang (Light)
  • Desain adaptif & responsif di semua ukuran layar
